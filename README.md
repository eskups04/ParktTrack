# ParktTrack
ParkTrack is a C++ console-based parking management system that handles vehicle entry, parking slot allocation, ticket issuing, and vehicle exits. It uses different data structures to organize and handle parking operations efficiently.

# Features
- Manage vehicle entry and exit
- Assign available parking lots
- Issue parking tickets
- Monitor parking slot availability
- Search vehicle using plate number
- Handle waiting vehicles using queue
- Update or reassign parking slots
- Display parking system summary
